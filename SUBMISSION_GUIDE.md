# Submission Guide

## Tools

Use:
- Microsoft Excel
- MySQL / MySQL Workbench
- Power BI Desktop
- A Generative AI tool
- GitHub

## Workflow

1. Fork the official NerdIT repository.
2. Use the provided `Sales_project.csv`.
3. Complete the Excel analysis.
4. Complete the SQL analysis in MySQL.
5. Complete the statistical analysis in Excel.
6. Build the 2-page Power BI dashboard.
7. Complete the AI analysis.
8. Prepare the short final report.
9. Add the completed files to your GitHub repository.
10. Submit your GitHub repository URL to NerdIT.

## Required Files

```text
EXCEL_ANALYSIS.xlsx
SQL_ANALYSIS.sql
STATISTICAL_ANALYSIS.xlsx
POWER_BI_DASHBOARD.pbix
AI_IN_BUSINESS_ANALYSIS.md
FINAL_REPORT.pdf
```

Python is not required. Keep the project simple and focus on business reasoning.
